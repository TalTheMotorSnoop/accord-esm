A/T Interlock System - Shift Lock Release, Release Spring, and Release Shaft Replacement
NOTE: This replacement applies for the LHD model.
  1. Remove the shift lever assembly.
  1. Remove the shift lever knob.
  1. Remove the shift lever boot and the A/T gear position indicator panel base.
  1. Release the lock (A) of the shift lock release (B), then remove the shift lock release and the release spring (C).
  1. Release the lock (D) of the shift lock release shaft (E), and remove the release shaft.
  1. Replace the shift lock release, the release spring, or the release shaft.
  1. Install the shift lock release spring (A) in the shift lock release (B).
  1. Install the shift lock release shaft (C) in the shift lever, and install the shift lock release and the release spring on the release shaft end.
  1. Make sure that the release spring end (A) is installed in the shift lock release (B), and other side end (C) of the release spring is on the catch (D).
  1. Install the shift lever boot and the A/T gear position indicator panel base.
  1. Install the shift lever knob.
  1. Install the shift lever assembly.

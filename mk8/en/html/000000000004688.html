R20A3 Engine Model
NOTE: Use fender covers to avoid damaging painted surfaces.
  1. Make sure the clutch disc position using the clutch alignment tools.
  1. Make sure the two dowel pins (A) are installed in prescribed hole on the engine block as shown.
  1. Check the release bearing, and reinstall the release bearing and the release fork with applying appropriate grease.
  1. Place the transmission on the transmission jack, and raise it to the engine unit level.
  1. Join the transmission and the engine unit with putting through the transmission mainshaft to the clutch pressure plate and the clutch disc until it becomes no gap between the transmission housing and the engine block.
  1. Install the lower transmission mounting bolts (A).

Rear side
  1. Install the clutch case cover (A).
  1. Install the intermediate shaft.
  1. Install both sides of driveshaft.
  1. Install the lower transmission mount (A) with new bolts.
  1. Install the front engine mount bracket (A) with new bolts.
  1. Install the rear engine mount bracket (A) with new bolts.
  1. Install the rear engine mount (A) with a new bolt.
    NOTE: The illustration shows equipped with a dynamic damper (B) type.
  1. Support the front subframe with a piece of wood and a jack.
  1. Position the steering gearbox washers (A) on the front subframe (B), and lift up the subframe. Do not contact with the subframe and body frame in this step.
  1. Loosely install new four front subframe mounting bolts with each stiffener, new rear stiffener mounting bolts (C), and the front stiffener mounting bolts (D).
  1. Align the front subframe using the subframe alignment pin (A). Vertically install the subframe alignment pin, and align the right-rear corner of the subframe and vehicle frame holes, then loosely tighten the subframe mounting bolt (B) until the front subframe contacts the body frame.
  1. Loosely tighten the left-rear subframe mounting bolt using the same procedure as the right-rear with the subframe alignment pin.
  1. Partially tighten the right and left front subframe mounting bolts.
  1. Tighten the right-rear subframe mounting bolt to the specified torque with the subframe alignment pin in the positioning hole.
  1. Tighten the left-rear subframe mounting bolt to the specified torque with the subframe alignment pin in the positioning hole.
  1. Tighten the right and left front subframe mounting bolts (A) to the specified torque.
  1. Tighten the rear and front stiffener mounting bolts to the specified torque.
  1. Check all of the front subframe mounting bolts, and retighten if necessary.
  1. Remove the jack and wood piece.
  1. Install the nuts (A) securing lower transmission mount.
  1. Connect the EPS ground subharness connector at the front of the front subframe.
  1. Install both sides of the front subframe mid mount (A) with new bolts.
  1. Install exhaust pipe A with the gaskets.
  1. Refill the MTF to the proper level.
  1. Install the splash shield.
  1. Connect the knuckle ball joint onto the lower arm.
  1. Install the damper fork.
  1. With HID lamp model: Connect the front suspension stroke sensor connector.
  1. Clean the mating surfaces of the brake disc and the inside of the wheel, then install the front wheels.
  1. Lower the vehicle on the lift.
  1. Install the upper transmission mounting bolts (A).
  1. Install transmission hanger C to the transmission housing.
  1. Loosely install the transmission mount bracket (A) to the transmission housing with new bolts.
  1. Loosely install new rear engine mount bolts (A).
  1. Connect the vacuum hose (A), then install the vacuum hose bracket (B).
  1. Loosely install new front engine mount bolt (C).
    NOTE: Install the engine mount stop (D) after tightening the front engine mount bolt to the specified torque.
  1. Remove the engine support hanger.
  1. Tighten the rear engine mount bolts to the specified torque.
  1. Tighten the transmission mount bolts to the specified torque.
  1. Tighten the front engine mount bolt to the specified torque, then install the engine mount stop with new nuts.
  1. Remove the subhanger stay (A) with the hook (B) of the engine support hanger.
  1. Install the harness holder bracket (C).
  1. Install the harness holder (A) to the bracket, then install the harness holder bolts.
  1. Install the engine mount control solenoid valve (B), then connect the EGR valve connector (C) and the engine coolant temperature (ECT) sensor 1 connector (D).
  1. Set back the hung up steering gearbox to regular position, then loosely install all new four steering gearbox mounting bolts with the top washers (A).
  1. Tighten the front/driver's side of the steering gearbox mounting bolt (B) to the specified torque.
  1. Tighten the front/passenger's side of the steering gearbox mounting bolt (C) to the specified torque.
  1. Tighten the rear/driver's side of steering gearbox mounting bolt (D) to the specified torque, then tighten the rear/passenger's side of the mounting bolt (E) to the specified torque.
